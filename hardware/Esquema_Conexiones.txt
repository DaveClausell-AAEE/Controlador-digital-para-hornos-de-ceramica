# ESQUEMA DE CONEXIÓN PCB - CONTROLADOR DE HORNO V13.0 (ARQUITECTURA INDUSTRIAL)
Este documento sirve como referencia para el cableado y diseño de PCB.

## 1. Módulo de Potencia (Entrada AC)
- AC-L (220V/110V) -> Fusible 1A -> Varistor 10D471K -> HLK-PM01 Pin AC-L
- AC-N (220V/110V) -> Varistor 10D471K -> HLK-PM01 Pin AC-N
- HLK-PM01 V+ (5V DC) -> Rail de 5V
- HLK-PM01 V- (GND) -> Rail de GND

## 2. Microcontrolador (ESP32 DevKit V1 - 38 Pin)
- Pin 5V (VIN) -> Conectar a Rail 5V
- Pin GND -> Conectar a Rail GND

## 3. Buses SPI Independientes (Aislamiento de Ruido)
### VSPI (Pantalla y Tarjeta SD)
- SCK: ESP32 GPIO 18 -> TFT_SCK, SD_SCK
- MISO: ESP32 GPIO 19 -> TFT_MISO, SD_MISO
- MOSI: ESP32 GPIO 23 -> TFT_MOSI, SD_MOSI
- TFT_CS: ESP32 GPIO 15
- SD_CS: ESP32 GPIO 33

### HSPI (Sensor MAX31855 - Crítico)
- SCK: ESP32 GPIO 14 -> MAX31855_CLK
- MISO: ESP32 GPIO 13 -> MAX31855_MISO
- MAX_CS: ESP32 GPIO 5

## 4. Pantalla TFT ILI9341
- VCC -> Rail 5V
- GND -> Rail GND
- DC / RS -> ESP32 GPIO 2
- RST -> ESP32 GPIO 4
- LED (BL) -> ESP32 GPIO 12 (Control de Brillo PWM)

## 5. Salidas (Control y Estado)
- Relé (SSR): ESP32 GPIO 17 (Active LOW)
- Buzzer: ESP32 GPIO 27
- LED RGB (R): GPIO 16
- LED RGB (G): GPIO 21
- LED RGB (B): GPIO 22

## 6. Pulsadores (Input Only - Requieren Pull-Up Externo 10k a 3.3V)
- Botón UP: **GPIO 36 (SVP)** <-> Pulsador a GND
- Botón DOWN: **GPIO 39 (SVN)** <-> Pulsador a GND
- Botón OK: **GPIO 34** <-> Pulsador a GND
- Botón EXIT: **GPIO 35** <-> Pulsador a GND
